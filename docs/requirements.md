# NGSL Go · 第一版

安卓平板家庭自用。只包含 NGSL 1.2，词表版本和学习记录分开，后续可扩展。

- 本机多学习者：成人、儿童，可随时切换，熟词筛选、每日任务、词汇进度、复习安排、故事和偏好全部隔离。
- ChatGPT 连接设备共用，参考 FCE-Go；不复制其他应用的凭据。
- 列表批量排除熟词，支持恢复。不将词频排名当作用户掌握程度。
- 简明中英文释义、词性、英美音标及朗读、搭配、双语例句。故事里突出当天词汇。
- 每日任务固定保存；到期复习优先，允许只复习。通过回忆结果安排下次复习。
- GPT 根据新词、复习词、目标用法和学习者类型生成短故事、翻译、搭配和回忆练习，检查通过后缓存。
- 固定词汇音频参考 FCE-Go 的预生成 Kokoro 方案。动态故事语音单独合成并缓存。
- 第一版数据保存在本机，无云同步。学习者档案不作为隐私或权限隔离系统。
