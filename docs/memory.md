# 统一记忆与复习机制

成人与儿童共用同一流程和调度逻辑，不新增识字程度或学习阶段设置。学习者的进度、每日计划、词卡内容、故事与练习记录仍独立保存。

## 学习流程

1. 新词先展示预置释义、发音、双语搭配及 B1–B2 语境例句。点“学好了，稍后回忆”只记录一次接触，不增加成功复习次数，也不完成当天任务。
2. 间隔后呈现回忆题，再显示答案供学习者核对。认读展示英文，听懂只提供发音，表达展示中文并要求说出英文和短句，拼写要求输入词条原形。
3. 认读、听懂、表达由学习者自评“没想起来／提示后想起／独立想起”；不进行语音识别或语义自动判分。拼写忽略首尾空白和大小写、统一英文撇号，其余按词条原形核对，不把错误词形或拼写自动判为正确。
4. 使用过提示，即使随后回答正确，也只能记录为提示后回忆。提示后想起和忘记均保留待练状态；独立想起后完成当天该词的任务。
5. 故事遮词练习单独记录自评结果，不通过阅读、查看答案或故事完成标记提升词卡复习间隔。

## 调度和负担

- 每组最多五个不同单词，每个单词每组最多三次提取尝试；结束时明确显示仍待练习的词，可返回首页或继续其他可练词。
- 新词接触或未独立回忆后，至少间隔一分钟；同一组内还需经过两个其他练习步骤才重新呈现。组内没有其他可用词时先结束，不立即循环。
- 同一天该词第三次及后续未独立回忆后，至少休息十分钟。等待时间同时保存在词进度与每日计划，关闭页面、重启、进入次日新计划不会绕过。
- 每个词每天默认练习一个方向，方向在计划中固定。先补上未成功的方向，再逐日引入其他方向，之后按到期日、间隔和固定顺序选取。
- 各方向拥有独立间隔和回忆记录。初次独立成功安排次日检查；跨日独立成功逐渐延长间隔。同日重复不放大间隔；提示后想起缩至一天，忘记后重新从短间隔开始。
- 每日新词设置上限六十个；新建每日计划最多八十词，到期复习优先，新词使用剩余名额。超过名额的到期词不删除、不标记完成，继续保留原到期状态。升级不会重写已生成计划；手动增加每日新词数时按所选额度追加新词，保留已学词、等待时间、完成标记和故事；明确手动增加可超过自动计划的八十词预算。降低数量保留今日任务，后续新计划按新数量安排。

五词、三次、一分钟、十分钟、每日八十词及间隔倍率都是当前版本的产品默认值，并非适合所有人的唯一科学参数。后续应以真实延迟回忆和使用负担评估效果。

## 已熟悉与筛词复制

- 词卡的“标记已熟悉”转入 `familiar`，保留此前的方向记录和复习历史，不产生独立回忆成功。下一次抽查至少十四天后；抽查独立成功后逐渐延长，最高一百二十天；使用提示或忘记后自动恢复常规学习。也可通过词卡手动恢复。
- 新计划在常规复习之后最多安排两个到期熟悉词抽查；没有入选的熟悉词保持到期状态。原快速筛词的 `known` 排除状态不自动转为熟悉或重置。
- 设置中的“把我的筛词结果复制给其他学习者”仅复制熟词/生词分类。接收者已经筛选、已学习、已熟悉或已排除的词跳过，保留其复习、故事、设置和缓存；原学习者完全不变。重复复制不会反复重写接收者记录。

## 数据兼容与统计

- 保持已有版本 1 的快照格式，按需添加字段，打开旧档案时不重置或改写数据。
- 原有复习记录仅作为认读方向的历史依据，不推断听懂、表达、拼写或跨日成功次数。
- `progress[wordId].memory` 保存各方向的间隔、到期日、复习次数、遗忘次数和跨日成功次数；顶层 `due` 取各方向最早的待练时间，未练方向安排后续日期。
- `plans[day].practice` 固定当天方向，保存尝试次数与等待时间。开始学习后保留原任务与完成标记；增加新词额度时只追加。保留重复评分保护。
- `practiceLog` 按学习者追加接触、提取和故事语境事件。记录方向、时间、提示使用、自评结果，拼写还记录输入；查看答案本身不产生提取成功记录。
- 首页“近 7 天跨日独立回忆”只统计同一方向曾在此前日期练习过的提取尝试；同日纠错后的重复不计为跨日成功。它是已有练习记录的计数，不是标准化记忆能力测验。
- 故事原有 `practiced` 标记保留，新增 `practiceResults` 保存明确自评。原标记不补造分数。
- 所有异步操作使用进入页面时的学习者 ID，继续采用串行、原子写入和上一份有效快照备份。

## 预计日期与再练今日单词

- 预计日期按尚未接触的新词、今日可学习的新词和每日新词额度计算，包含今天；熟词筛除和已进入学习的词不再计入。零额度不显示虚构完成日期。该日期仅代表首轮新词接触，不等于完成长期掌握，复习负担较多时会顺延。
- 今日词卡完成后可再次练习同一天的单词。该轮使用独立的临时队列，不清空每日完成标记，不覆盖原计划；关闭页面后可重新开始一轮。
- 再练事件保存为 `sameDayPractice`，不计为跨日独立回忆。独立成功保持既有进度和到期日；忘记或使用提示按实际方向回到短间隔，熟悉词恢复常规学习，同时保留今日任务完成记录。重学等待时间仍保存到进度，不能通过重开跳过。跨午夜的旧页面不能向新一天写入再练结果。
