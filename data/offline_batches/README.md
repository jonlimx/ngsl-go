# 全量离线词卡

`cards_1.json` 至 `cards_6.json` 是大模型一次性原创生成的静态教学内容，覆盖全部 2,809 个 NGSL 1.2 词条。每个 ID 对应一个约 14～24 词的 B1–B2 英语语境句、完整中文译文及两条不同的双语常用搭配。允许自然句子最长 32 词。内容包含条件、原因、让步和关系从句，避免只有单词含义而没有情境的例句。没有使用 Tatoeba 或商业词典例句。

`input_*.json` 保存生成时的目标词、官方义项及词形，便于检查覆盖和义项对应。少数官方中文释义明显错误的词通过可选 `chinese` 字段修正显示，原始来源字段、词条 ID 和排名保留。内容遵循对应英文义项，不混用同形异义词的词形。

生成仅在开发阶段进行，不会在平板上再次调用模型。`tooling/import_ngsl.py` 导入前检查精确 ID 覆盖、句长、完整句、目标词边界、中文译文、两条不同搭配、占位符及重复句；校验失败不更新应用词库。导入后的资产另外由 `tooling/test_word_material.py` 检查，每次构建安装前执行。

语义与译文仍可能存在模型错误；构建时的程序检查不能证明每句语言质量。应结合目标英文义项抽查多义词、易混词与不规则词形，并修正具体问题。未提供的词族或反义词不表示不存在，也不机械补造。
